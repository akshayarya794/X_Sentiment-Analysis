# X_Sentiment-Analysis
Objective: Multiclass emotion classification from raw text data.  NLP Techniques: Text cleaning, Tokenization, Stopword removal, CountVectorizer, and N-gram TF-IDF.  Algorithms Tested: Multinomial Naive Bayes, Logistic Regression, LightGBM, LinearSVC.  Best Result: ~90.37% accuracy using a tuned LinearSVC model with Bigram TF-IDF features.
